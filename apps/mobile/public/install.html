DOWNLOAD NARCODEX.IPA

A free personal Apple ID can run this app for 7 days. Apple does not let Safari install that file. A paid developer signature is what makes an IPA install from the browser. A free Apple ID signs the app on your phone through AltStore or SideStore.

  1. Install AltServer from altstore.io on a computer, then install AltStore on the iPhone with your personal Apple ID. SideStore is the same idea after one computer setup.
  2. Download the IPA in Safari. In AltStore, choose the plus button and open the file. Or add this source: https://narcodex.surge.sh/source.json
  3. Turn on Developer Mode in Settings, Privacy & Security. Restart the phone.
  4. Trust your Apple ID under Settings, General, VPN & Device Management.
  5. Refresh the app before the 7 days run out. AltStore does that while AltServer is on the same Wi-Fi.

The archive inside the app loads from this site, so the phone needs a connection the first time it opens.
