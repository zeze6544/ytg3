NARCØDEX.apk

This is the Android app. Chrome on a Samsung phone can download it and the system installer can install it.

DOWNLOAD NARCODEX.APK
  1. Open this page in Chrome on the phone.
  2. Tap the download. If Chrome warns that the file can harm your device, that is the normal warning for an app that is not from the Play Store. Confirm the download.
  3. When the download finishes, tap Open. If Android blocks it, go to Settings, Security and privacy, Install unknown apps, Chrome, and allow installs from this source. Then open the file again.
  4. Confirm the install. The app is named NARCØDEX, package com.narcodex.archive.

The first open reads the catalogue stored in the app. Extra catalogue files load from the public site when the phone is online.
